    Control groups

    Spaced visual actions and connected, named semantic control groups.

    Control groups

    .group is a spaced visual action layout that adds no accessibility semantics and stacks on narrow screens. Use it when nearby actions do not need a group announced. role="group" creates a connected semantic control group with collapsed borders and no button shadows; it stacks as a connected vertical group on narrow screens. Give a semantic group an accessible name with aria-labelledby or aria-label. Both layouts act on their direct children.

    Visual .group

    <div class="group">
  <button type="button">Deploy</button>
  <button type="button" class="secondary">Save draft</button>
  <button type="button" class="outline">Cancel</button>
</div>

    Semantic role="group"

    Log window

    <p id="log-window-label">Log window</p>
<div role="group" aria-labelledby="log-window-label">
  <button type="button" aria-pressed="true">15 minutes</button>
  <button type="button" aria-pressed="false" class="secondary">1 hour</button>
  <button type="button" aria-pressed="false" class="secondary">24 hours</button>
</div>

    Button groups

    Use .group to lay out separate actions with space between them; each button keeps its normal shadow. Use role="group" for connected semantic controls: adjacent borders collapse and individual button shadows are removed. Every semantic group requires an accessible name from aria-label or aria-labelledby. On narrow screens, its controls stack vertically while remaining connected.

    <div role="group" aria-label="Deployment actions">
  <button type="button">Deploy</button>
  <button type="button" class="secondary">Preview</button>
  <button type="button" class="outline">Cancel</button>
</div>
