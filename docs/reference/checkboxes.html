    Checkboxes

    Native checkboxes for independent choices and indeterminate selections.

    Usage

    Checkboxes represent independent choices. Keep a visible label and a useful form name; checked controls submit their values, while unchecked controls are omitted. Use a fieldset and legend to name related options.

    Index options 
    <fieldset>
              <legend>Index options</legend>
              <label><input name="full-text" type="checkbox" checked> Build full-text index</label>
              <label><input name="analytics" type="checkbox"> Enable analytics</label>
            </fieldset>

    Use native disabled when unavailable. See the form validation guide for errors and help text.

    Indeterminate checkbox

    indeterminate is a JavaScript property, not an HTML attribute, and it affects presentation rather than the submitted checked value. Set it after the checkbox exists in the DOM and update it when child selections change.

    <label><input id="select-services" name="select-services" type="checkbox"> Select all services</label>
<script>
  document.getElementById("select-services").indeterminate = true;
</script>
