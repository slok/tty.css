    Progress & meters

    Use progress for task completion and meters for scalar measurements within known bounds.

    Task progress

    Use progress for task completion. Include value for determinate work and omit it while the amount is unknown. For scalar measurements within a known range, use a meter instead.

    68%Scanning
    <label for="build-progress">Build progress</label>
<progress id="build-progress" value="68" max="100">68%</progress>

<label for="scan-progress">Scanning repository</label>
<progress id="scan-progress">Scanning</progress>

    Textured progress

    Add class="textured" to a native progress with value for a continuous Dense SVG-mask fill over a muted --tty-border track. The bar is 1rem high with no outline, frame, or box shadow. Its fill uses currentColor; customize it with CSS color, not a role.

    By default, the fill follows text color: black in the default light theme, light in the dark theme. The accent-colored example below explicitly overrides color.

    68%68%
    <label for="textured-progress-default">Default — inherited text color</label>
<progress class="textured" id="textured-progress-default" value="68" max="100">68%</progress>

<label for="textured-progress">Custom — theme accent color</label>
<progress class="textured" id="textured-progress" value="68" max="100"
  style="color: var(--tty-accent)">68%</progress>

    Optional progress pattern tokens change the mask and tile size independently of frame shadows. Without value, progress.textured keeps the existing indeterminate style. Ordinary progress and meters are unchanged, and no framework JavaScript is needed. In forced-colors mode, the native fallback uses no mask and a Highlight fill.

    Fallback text is useful where the elements are unsupported but is not a visible numeric label in modern browsers. Show a separate text value when the exact number matters.

    Meters

    Use meter for a scalar measurement within a known range, not task completion. min and max define bounds; low, high, and optimum describe which values are desirable. The browser chooses optimum, suboptimum, or poor-range presentation, using the shared success, warning, and danger colors where exposed.

    62%
    <label for="cache-meter">Cache utilization</label><meter id="cache-meter" min="0" max="100" low="35" high="80" optimum="60" value="62">62%</meter>

    Provide a visible label. Fallback text is not a visible numeric label in modern browsers, so show a separate value when the exact number matters. Use progress for task completion, and check meter presentation across your target browsers.
