    Forms & validation

    Compose native controls with labels, helpers, shared states, and validation.

    Form basics

    Associate each control with a visible label. A matching for and id keeps the label clickable and gives the control an accessible name. Use help text with aria-describedby; placeholders are examples, not labels.

    A small immediately after a text-like input, select, or textarea gets muted block helper styling and a negative top margin, regardless of ancestry. Input types checkbox, radio, range, hidden, button, submit, and reset are excluded. For wrapped or grouped controls, use small.helper: it uses margin: 0 0 1rem, even directly after a control. IDs and wrappers alone do not imply helpers.

    Use a unique deployment name. 
    <form>
  <label for="project-name">Project name</label>
  <input id="project-name" name="project" type="text" placeholder="search-production" aria-describedby="project-help">
  <small id="project-help">Use a unique deployment name.</small>

  <label for="project-region">Region</label>
  <select id="project-region" name="region">
    <option value="">Choose a region</option>
    <option value="us-east">US East</option>
    <option value="eu-central">EU Central</option>
  </select>

  <label for="project-notes">Deployment notes</label>
  <textarea id="project-notes" name="notes" rows="4" placeholder="Optional context for operators"></textarea>
</form>
    Keep this token private. 
    <label>API token <input name="api-token" type="password" aria-describedby="token-help"></label>
<small class="helper" id="token-help">Keep this token private.</small>

    Common states

    Browsers submit enabled controls, including read-only controls. Disabled controls are not editable, focusable, or submitted. Use readonly when a value still belongs in the submission and disabled when the control is unavailable.

    <div class="grid">
  <div>
    <label for="state-default">Default</label>
    <input id="state-default" name="default" type="text" value="Editable value">
  </div>
  <div>
    <label for="state-placeholder">Placeholder</label>
    <input id="state-placeholder" name="placeholder" type="text" placeholder="Enter a value">
  </div>
  <div>
    <label for="state-readonly">Read-only</label>
    <input id="state-readonly" name="readonly" type="text" value="Submitted value" readonly>
  </div>
  <div>
    <label for="state-disabled">Disabled</label>
    <input id="state-disabled" name="disabled" type="text" value="Unavailable value" disabled>
  </div>
</div>

    Validation

    Set aria-invalid="true" only when a field is known to be invalid and connect its message with aria-describedby. ARIA defines aria-invalid="false" as explicitly valid; there is no aria-valid attribute. ARIA communicates state but does not perform validation or prevent submission.

    Email address verified.
    Enter an address containing @. 
    <form>
  <div class="grid">
    <div>
      <label for="valid-email">Verified email</label>
      <input id="valid-email" name="valid-email" type="email" value="ops@example.com" aria-invalid="false" aria-describedby="valid-email-message">
      <small id="valid-email-message">Email address verified.</small>
    </div>
    <div>
      <label for="invalid-email">Email with an error</label>
      <input id="invalid-email" name="invalid-email" type="email" value="ops.example.com" aria-invalid="true" aria-describedby="invalid-email-message">
      <small id="invalid-email-message">Enter an address containing @.</small>
    </div>
  </div>
</form>

    Browser validation and :user-invalid

    tty.css also styles :user-invalid. The pseudo-class follows native constraint validation after the browser considers the user to have interacted with the field, often after a submission attempt. Exact timing and validation messages vary by browser. Try submitting this empty required field.

    Enter at least three characters. 
    <form>
  <label for="required-cluster">Cluster name</label>
  <input id="required-cluster" name="cluster" type="text" required minlength="3" aria-describedby="cluster-requirements">
  <small id="cluster-requirements">Enter at least three characters.</small>
  <button type="submit">Validate</button>
</form>
