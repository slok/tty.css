Tables & code

Tables keep technical data dense and legible. Code, keyboard input, and preformatted blocks use the shared monospace system.

Accessible tables

Use a caption for the table's purpose, scope="col" for column headers, and scope="row" for row headers. Wrap wide tables in .overflow-auto; a focusable, labelled wrapper lets keyboard users reach and identify the scroll region.

Table variants

Variants are opt-in and composable. .striped alternates body rows, .hoverable highlights the pointed row, .bordered adds vertical cell rules, and .compact reduces padding and type size. Hover is visual feedback only, so do not use it as the sole indication of selection or status.

Inline code and keyboard input

Use code for identifiers and fragments, kbd for user input, and samp for program output.

Set data-theme="dark", press Command + K, and expect Theme updated.

<p>Set <code>data-theme="dark"</code>, press <kbd>Command</kbd> + <kbd>K</kbd>, and expect <samp>Theme updated</samp>.</p>

Code blocks

Wrap complete preformatted fragments in pre > code. Horizontal overflow remains scrollable and whitespace is preserved.

const query = {
  rankBy: ["vector", "ANN", embedding],
  topK: 10,
};
<pre><code>const query = {
  rankBy: ["vector", "ANN", embedding],
  topK: 10,
};</code></pre>
