    Switches

    On/off switches using native checkbox form behavior.

    Usage

    A checkbox with role="switch" exposes an on/off switch while preserving native checkbox form behavior. Use a stable visible label. Checked controls submit their values; unchecked controls are omitted.

    Runtime features 
    <fieldset>
              <legend>Runtime features</legend>
              <label><input name="autoscaling" type="checkbox" role="switch" checked> Autoscaling</label>
              <label><input name="maintenance" type="checkbox" role="switch"> Maintenance mode</label>
            </fieldset>

    Use native disabled when unavailable. See the form validation guide for errors and help text.
