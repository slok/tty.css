    Code blocks

    Preformatted code and text diagrams with preserved whitespace and scrollable overflow.

    Code blocks

    Wrap complete preformatted fragments in pre > code. Horizontal overflow remains scrollable and whitespace is preserved.

    const query = {
  rankBy: ["vector", "ANN", embedding],
  topK: 10,
};
    <pre><code>const query = {
  rankBy: ["vector", "ANN", embedding],
  topK: 10,
};</code></pre>

    ASCII diagrams

    Preformatted text also suits text diagrams. Add an accessible name when the surrounding prose does not explain the diagram.

    client --API--> cache --> object storage
                    |
                    +---> search index
    <pre role="img" aria-label="Request flow from client to cache and storage"><code>client --API--&gt; cache --&gt; object storage
                    |
                    +---&gt; search index</code></pre>
