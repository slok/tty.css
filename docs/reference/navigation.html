Components

Navigation

Navigation uses semantic lists of destinations, wraps on narrow screens, and can include native disclosure dropdowns or clearly separated actions.

Basic navigation

Use one or more lists inside a labelled nav. A label distinguishes this landmark from other navigation regions; aria-current="page" identifies and emphasizes the current destination.

  • Console
  • Overview
  • Queries
  • Settings
<nav aria-label="Console navigation">
  <ul>
    <li><a href="#basic"><strong>Console</strong></a></li>
  </ul>
  <ul>
    <li><a href="#basic" aria-current="page">Overview</a></li>
    <li><a href="#breadcrumbs">Queries</a></li>
    <li><a href="#actions">Settings</a></li>
  </ul>
</nav>

Breadcrumbs

Breadcrumb styling has two equivalent entry points: add .breadcrumb, or use the exact label aria-label="breadcrumb". Use an ordered path in source order and put aria-current="page" on the final item. tty.css draws dashed separators without adding spoken characters.

  • Home
  • Namespaces
  • search-production
  • Home
  • Settings
  • API keys
<div class="grid">
  <nav class="breadcrumb" aria-label="Breadcrumb">
    <ul>
      <li><a href="#breadcrumbs">Home</a></li>
      <li><a href="#breadcrumbs">Namespaces</a></li>
      <li aria-current="page">search-production</li>
    </ul>
  </nav>
  <nav aria-label="breadcrumb">
    <ul>
      <li><a href="#breadcrumbs">Home</a></li>
      <li><a href="#breadcrumbs">Settings</a></li>
      <li aria-current="page">API keys</li>
    </ul>
  </nav>
</div>

Link dropdown

details.dropdown is a select-like disclosure. Outside navigation it fills the available width; its direct list opens as an overlay. Links remain ordinary destinations.

Choose documentation
  • Quick start
  • Components
  • Accessibility
<details class="dropdown">
  <summary>Choose documentation</summary>
  <ul>
    <li><a href="#link-dropdown">Quick start</a></li>
    <li><a href="#link-dropdown">Components</a></li>
    <li><a href="#link-dropdown">Accessibility</a></li>
  </ul>
</details>

Checkbox dropdown

Menu rows may contain labelled checkboxes for multiple independent choices. Give each control a useful name; clicking a checkbox does not need to close the native disclosure.

Select services
<details class="dropdown">
  <summary>Select services</summary>
  <ul>
    <li><label><input type="checkbox" name="services" value="search" checked> Search</label></li>
    <li><label><input type="checkbox" name="services" value="storage"> Storage</label></li>
    <li><label><input type="checkbox" name="services" value="events"> Events</label></li>
  </ul>
</details>

Button dropdown and alignment

Direct buttons are styled as full-width action rows. Add .align-right to the dropdown to physically anchor the overlay to the right.

Workspace actions
<details class="dropdown align-right">
  <summary>Workspace actions</summary>
  <ul>
    <li><button type="button">Create workspace</button></li>
    <li><button type="button">Import settings</button></li>
    <li><button type="button">Sign out</button></li>
  </ul>
</details>

Validation states

Put aria-invalid="true" or aria-invalid="false" on the summary for invalid and explicitly valid borders. Connect explanatory text with aria-describedby; there is no aria-valid attribute.

Region: US East
  • US East
  • EU Central
Region is available.
Choose a region
  • US East
  • EU Central
A deployment region is required.
<div class="grid">
  <div>
    <details class="dropdown">
      <summary aria-invalid="false" aria-describedby="region-valid">Region: US East</summary>
      <ul>
        <li><a href="#validation">US East</a></li>
        <li><a href="#validation">EU Central</a></li>
      </ul>
    </details>
    <small id="region-valid">Region is available.</small>
  </div>
  <div>
    <details class="dropdown">
      <summary aria-invalid="true" aria-describedby="region-error">Choose a region</summary>
      <ul>
        <li><a href="#validation">US East</a></li>
        <li><a href="#validation">EU Central</a></li>
      </ul>
    </details>
    <small id="region-error">A deployment region is required.</small>
  </div>
</div>

Dropdown inside navigation

Inside a nav, a plain dropdown summary becomes compact and the disclosure no longer fills the row. Keep the navigation landmark labelled.

  <ul>
    <li><a href="#nav-dropdown" aria-current="page">Dashboard</a></li>

      <details class="dropdown align-right">
        <summary>Project: Atlas</summary>
        <ul>
          <li><a href="#nav-dropdown">Atlas</a></li>

Navigation actions

Buttons may appear in navigation when they perform an action. Destinations remain links, and every button should declare its type.

  • Deployments
  • Logs
<nav aria-label="Deployment navigation">
  <ul>
    <li><a href="#actions" aria-current="page">Deployments</a></li>
    <li><a href="#actions">Logs</a></li>
  </ul>
  <ul>
    <li><button type="button" class="secondary">Refresh</button></li>
    <li><button type="button">New deployment</button></li>
  </ul>
</nav>

Native and application behavior

The browser makes details and summary operable by keyboard and pointer, exposes expanded state, and toggles the disclosure without JavaScript. These are disclosure lists, not ARIA menus, so do not add role="menu" or menu keyboard behavior to otherwise native markup.

tty.css only provides presentation. Application code is responsible for updating a choice summary, closing after selection when appropriate, closing on outside interaction or Escape if required, running button actions, and keeping validation messages and state synchronized. Preserve native link navigation and checkbox behavior when enhancing a dropdown.
