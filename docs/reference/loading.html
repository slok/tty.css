    Loading states

    Busy regions and loading indicators with meaningful labels and application-owned state.

    Busy and loading states

    aria-busy="true" exposes a busy region or control and adds an outlined square spinner with a solid center to non-form elements. It turns in quarter-turns with short pauses, using only CSS and the current text color—no SVGs, font characters, or framework JavaScript. Primary, secondary, contrast, and outline buttons keep their variant styling.

    Indexing documents

    <p aria-busy="true">Indexing documents</p>
<p class="group">
  <button type="button" aria-busy="true" disabled>Deploying</button>
  <button type="button" class="secondary" aria-busy="true" disabled>Synchronizing</button>
  <button type="button" class="contrast" aria-busy="true" disabled>Scanning</button>
  <button type="button" class="outline" aria-busy="true" disabled>Refreshing</button>
</p>
    • Set the attribute only while work is pending, then remove it or set it to false.
    • aria-busy does not prevent activation. Use native disabled while a form control must be unavailable, then remove both attributes when the operation completes.
    • A busy state does not guarantee that status text is announced. Put changing status in a suitable live region when users need asynchronous updates.
    • The spinner is decorative generated content with no text glyph to announce. It stays visible as a static square under reduced motion and follows system text colors in forced-colors mode. Keep a meaningful text label.
