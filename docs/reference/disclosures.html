    Disclosures

    Native details and summary elements for expandable content and accordions.

    Details and disclosure

    details and summary provide disclosure semantics, keyboard operation, and an exposed open state without JavaScript. Ordinary disclosures keep their default frame. Add .plain to details:not(.dropdown) to opt into a borderless, transparent surface, including inside fieldsets, while retaining contextual padding and the chevron; dropdowns are unaffected.

    Why use a native disclosure?

    It works before application JavaScript loads.

    Can it contain rich content?

    Yes. Add paragraphs, lists, forms, or other appropriate content.

    Need a quieter disclosure?

    Opt in with .plain; padding and the chevron remain.

    <details open>
  <summary>Why use a native disclosure?</summary>
  <p>It works before application JavaScript loads.</p>
</details>
<details>
  <summary>Can it contain rich content?</summary>
  <p>Yes. Add paragraphs, lists, forms, or other appropriate content.</p>
</details>
<details class="plain" open>
  <summary>Need a quieter disclosure?</summary>
  <p>Opt in with .plain; padding and the chevron remain.</p>
</details>

    Fieldset variant

    Direct-child disclosures inside a fieldset become divided rows. Use this for related settings or questions; see the base fieldset guidance.
