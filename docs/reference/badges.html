    Badges

    Compact square labels for tags, counts, and statuses.

    Usage

    Add .badge to a span for a compact, square tag, count, or status label. The default is neutral; .info, .success, .warning, and .danger reuse the notice palette for a colored border and subtle tint. Text keeps the theme foreground color.

    Backend New Active Pending Failed

    Production Healthy

    <span class="badge">Backend</span>
<span class="badge info">New</span>
<span class="badge success">Active</span>
<span class="badge warning">Pending</span>
<span class="badge danger">Failed</span>

    Badges are non-interactive labels, not buttons. Keep meaningful text rather than conveying status by color alone. Static badges need no ARIA role; the application owns announcements for dynamic status changes. Long labels wrap within the available width.

    Use mark for text highlighted for relevance, such as a search match; use a badge for tags and statuses. Badge corners stay square independently of the control and frame radius tokens.
