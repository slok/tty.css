    Fieldsets

    Name related form controls with fieldsets and legends, including disclosure rows.

    Fieldsets and legends

    Use fieldset and legend to name a related set of controls. A disabled fieldset disables its descendant controls except descendants of its first legend. A read-only fieldset does not exist in HTML; apply readonly to each supported control instead.

    Deployment identity
    Unavailable environment 
    <div class="grid">
  <fieldset>
    <legend>Deployment identity</legend>
    <label for="deployment-id">Deployment ID</label>
    <input id="deployment-id" name="deployment-id" type="text" value="dep_01J8M4" readonly>
    <label for="deployment-owner">Owner</label>
    <input id="deployment-owner" name="deployment-owner" type="text" value="Platform team" readonly>
  </fieldset>
  <fieldset disabled>
    <legend>Unavailable environment</legend>
    <label for="disabled-environment">Environment</label>
    <select id="disabled-environment" name="environment">
      <option value="production">Production</option>
    </select>
    <label><input name="protect-environment" type="checkbox" checked> Protect environment</label>
  </fieldset>
</div>

    Disclosure rows in a fieldset

    Place details directly inside a fieldset to create divided disclosure rows. Native summary elements remain keyboard-operable and communicate their expanded state without JavaScript. The direct-child relationship is required for this fieldset-specific presentation.

    Advanced deployment settings
    Health checks
    Shutdown behavior 
    <fieldset>
  <legend>Advanced deployment settings</legend>
  <details open>
    <summary>Health checks</summary>
    <label for="health-path">HTTP path</label>
    <input id="health-path" name="health-path" type="text" value="/healthz">
  </details>
  <details>
    <summary>Shutdown behavior</summary>
    <label for="grace-period">Grace period in seconds</label>
    <input id="grace-period" name="grace-period" type="number" min="0" max="300" value="30">
  </details>
</fieldset>
