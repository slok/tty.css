    Radio buttons

    Native radio buttons for one choice from a named group.

    Usage

    Radio buttons share a name so only one option can be selected. Give each option a distinct value and visible label; use a fieldset and legend to name the group. Native arrow-key behavior is preserved.

    Visibility 
    <fieldset>
              <legend>Visibility</legend>
              <label><input name="visibility" type="radio" value="private" checked> Private</label>
              <label><input name="visibility" type="radio" value="public"> Public</label>
            </fieldset>

    Use native disabled when unavailable. See the form validation guide for errors and help text.
