    Tables

    Accessible data tables, scroll regions, and composable appearance variants.

    Accessible tables

    Use a caption for the table's purpose, scope="col" for column headers, and scope="row" for row headers. Wrap wide tables in .overflow-auto; a focusable, labelled wrapper lets keyboard users reach and identify the scroll region.

    Query latency by operation
    Operationp50p90State
    Vector query14 ms17 msNominal
    Text search13 ms18 msNominal
    Document write165 ms248 msWatching
    <div class="overflow-auto" tabindex="0" role="region" aria-label="Query latency by operation">
  <table>
    <caption>Query latency by operation</caption>
    <thead>
      <tr>
        <th scope="col">Operation</th>
        <th scope="col">p50</th>
        <th scope="col">p90</th>
        <th scope="col">State</th>
      </tr>
    </thead>
    <tbody>
      <tr><th scope="row">Vector query</th><td>14 ms</td><td>17 ms</td><td>Nominal</td></tr>
      <tr><th scope="row">Text search</th><td>13 ms</td><td>18 ms</td><td>Nominal</td></tr>
      <tr><th scope="row">Document write</th><td>165 ms</td><td>248 ms</td><td>Watching</td></tr>
    </tbody>
  </table>
</div>

    Table variants

    Variants are opt-in and composable. .striped alternates body rows, .hoverable highlights the pointed row, .bordered adds vertical cell rules, and .compact reduces padding and type size. Hover is visual feedback only, so do not use it as the sole indication of selection or status.
