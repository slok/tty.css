    Native range inputs with visible output for exact values.

    Range inputs

    These controls keep browser-native interaction and accessibility while tty.css styles the exposed parts. Their internal widgets, dialogs, selected-file text, and color pickers differ across browsers and operating systems. Always provide a label.

    Native output uses tabular numerals by default, without imposing text alignment. Application code updates its value, as in the range example below. Show an output when the exact value matters.

    <label for="replica-range">Replica target: <output for="replica-range">4</output></label>
          <input id="replica-range" name="replica-target" type="range" min="1" max="8" step="1" value="4" oninput="this.previousElementSibling.querySelector('output').value = this.value">
