How the parameters work

OKLCH separates lightness, chroma, and hue. Hue chooses the color; chroma sets its intensity. tty.css chooses lightness for each role and mode, making related shades easier to create.

Accent parameters control buttons, links, selection, and general focus. Neutral parameters control surfaces, text, borders, code, and control focus. Status colors and SVG icons remain independent.

High chroma may exceed your display's gamut, so the browser maps colors to what it can show.

See parameter defaults, all color tokens, and accessibility guidance.

Need finer control? Full overrides

If the parameters aren't enough, override individual tokens such as --tty-bg or --tty-accent. You can pin just one color or define a full palette, as Monokai does. Match the mode selectors in the variable reference.
