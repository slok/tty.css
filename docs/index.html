Start from the markup.

Semantic

Native elements carry structure, behavior, and accessibility before CSS arrives.

<article>
  <h2>Status</h2>
  <progress value="86" max="100">
</article>

Class-light

Classes are reserved for composition and visual variants—not every declaration.

  • .container
  • .grid
  • .group
  • .legend

Adaptable

Light, dark, and automatic themes share a focused CSS-variable API.

<html data-theme="auto">

Colors: hex & OKLCH palettes →

Quick install

Use jsDelivr for automatic minification and compression.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/slok/tty.css@main/tty.min.css">

@main follows the latest main branch; pin a release tag or commit for production.

Prefer hosting locally? Download tty.css and link it from your document head.
