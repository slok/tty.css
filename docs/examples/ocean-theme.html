Ocean: one hue, related shades.

This palette sets framework parameters: --tty-accent-hue: 245, --tty-accent-chroma: 0.1, --tty-neutral-hue: 245, and --tty-neutral-chroma: 0.025. tty.css derives its semantic color tokens in OKLCH for light, dark, and automatic modes.

Compare Plum: the same tonal structure with a different hue. Cycle the theme button to inspect light, dark, and automatic mode.

Ocean workspace

Canvas, header bands, frames, and text share a hue with restrained chroma. Accents use a stronger chroma.

/* Application CSS loaded after ocean-theme.css */
:root {
  --tty-accent-hue: 315;
}

Changing --tty-accent-hue changes brand colors only. Optionally set --tty-neutral-hue: 315 too to tint surfaces, text, and borders. Changing hue does not guarantee contrast or keep every color inside your display's gamut: recheck the resulting palette.
