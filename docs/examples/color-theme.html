Mix parameters and direct overrides

For a new theme, load this CSS after tty.css instead of the full Forest palette. Let the framework derive brand colors, then pin an individual token on the active theme selectors:

:root {
  --tty-accent-hue: 145;
}

:root,
:root[data-theme="dark"],
:root[data-theme="auto"] {
  --tty-accent: #86efac;
}

The direct --tty-accent override wins; other brand tokens still follow --tty-accent-hue. Surfaces keep the default neutral palette unless you also set --tty-neutral-hue. Check contrast in each mode when mixing derived and custom colors. This snippet is not applied to the Forest preview.
