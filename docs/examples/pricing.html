Good to know

How does the monthly usage floor work?

Your usage counts toward the plan's minimum. A sandbox workspace with $18 of metered activity pays $24, not $42.

Can I change plans as my project grows?

Yes. Shared workspaces can move between sandbox and studio at the next billing boundary. Dedicated capacity is scheduled with your technical partner.

What is a billable record?

A record consists of a float32 embedding and its metadata. This example counts four bytes per embedding value plus the metadata size you select.

Will an idle collection keep generating charges?

Stored data continues to accrue storage charges. There is no query charge when you are not searching, and no write charge when you are not sending records.

Are development and production features different?

The retrieval API is the same on every plan. Higher tiers add operational controls, reserved capacity, and closer engineering support.

What happens after the included collection allowance?

The first 100 collections have no separate fee. Additional collections cost $0.10 each per month in this illustrative model.

Does the estimator include data transfer?

No. The simplified estimator shows storage, ingestion, search requests, and collection fees. Network transfer and optional services would be listed separately in a real quote.

How are dedicated workspaces priced?

This example applies a 25% premium to metered usage and a $2,400 monthly floor for reserved infrastructure and operational support.

Can I bring an existing search index?

You can stream records into a new collection, validate relevance, and switch traffic when you are ready. Keep the previous system running during the transition.
