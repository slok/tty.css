The basic idea

<aside class="notice warning" aria-labelledby="maintenance-title">
  <h3 id="maintenance-title">Scheduled maintenance</h3>
  <p>Uploads may be interrupted briefly.</p>
</aside>

A class chooses appearance, not announcements. Use an appropriate element for the context; reserve role="status" or role="alert" for actual dynamic announcements.

Base notices, tones, outline, and strong treatments come from tty.css. Extra experiments and demo behavior are local to this page. Icons from Pixel Icon Library by HackerNoon · License.
