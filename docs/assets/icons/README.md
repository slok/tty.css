# Documentation appearance icons

Icons from [Pixel Icon Library by HackerNoon](https://pixeliconlibrary.com/).

Source: [hackernoon/pixel-icon-library](https://github.com/hackernoon/pixel-icon-library/tree/5fe05c9c81a3eb43448e820b4521307102c248e7/icons/SVG/regular),
commit `5fe05c9c81a3eb43448e820b4521307102c248e7`:

- `brightness-high.svg`: light appearance.
- `moon.svg`: dark appearance.
- `laptop.svg`: automatic/system appearance.

The source repository supplies these files under the [MIT license](LICENSE),
preserved here. See also the library website's [license information](https://pixeliconlibrary.com/license/).

The original geometry is unchanged. The three SVGs are combined into
`pixel.svg` as named symbols, with `currentColor` presentation and decorative
semantics supplied by the referencing button. These assets are docs-only;
tty.css itself has no icon dependency.
