# Site icons

Icons from [Pixel Icon Library by HackerNoon](https://pixeliconlibrary.com/).

Source: [hackernoon/pixel-icon-library](https://github.com/hackernoon/pixel-icon-library/tree/5fe05c9c81a3eb43448e820b4521307102c248e7/icons/SVG),
commit `5fe05c9c81a3eb43448e820b4521307102c248e7`:

- `regular/brightness-high.svg`: light appearance.
- `regular/moon.svg`: dark appearance.
- `regular/laptop.svg`: automatic/system appearance.
- `brands/github.svg`: project repository links.

The source repository supplies these files under the [MIT license](LICENSE),
preserved here. See also the library website's [license information](https://pixeliconlibrary.com/license/).

The original geometry is unchanged. The SVGs are combined into
`pixel.svg` as named symbols, with `currentColor` presentation and decorative
semantics supplied by the referencing button or link. These assets are docs-only;
tty.css itself has no icon dependency.
